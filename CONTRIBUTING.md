# Contributing

Holdline treats code review as part of the build.

Before merging any substantive change:

1. Open a GitHub pull request.
2. Run the relevant checks locally.
3. Have the PR reviewed by Qodo.
4. Address review feedback before merging.

Direct pushes to `main` do not count as reviewed work for this project.

For hackathon submissions, prefer small PRs that are easy to review and explain in the review thread.
